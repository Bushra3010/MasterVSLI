Cheatsheet

VLSI glossary.

The acronyms that come up in every interview, in one line each.

RTL
Register Transfer Level
Abstraction describing the flow of data between registers and the logic between them.
UVM
Universal Verification Methodology
SystemVerilog class library standardising reusable testbench architecture.
SVA
SystemVerilog Assertions
Temporal properties that check design behaviour in simulation and formal.
STA
Static Timing Analysis
Vector-less analysis of timing paths across PVT corners.
DFT
Design for Test
Adding scan, BIST and ATPG hooks so silicon can be tested post-fab.
GLS
Gate-Level Simulation
Simulating the synthesised netlist, with or without SDF timing.
CTS
Clock Tree Synthesis
Buffering and balancing clock distribution to minimise skew.
OCV
On-Chip Variation
Derates that account for systematic and random process variation.
UPF
Unified Power Format
Side-file describing power intent — domains, isolation, retention.
AMBA
ARM AMBA
The standard on-chip bus family — APB, AHB, AXI.
LTSSM
Link Training and Status State Machine
The PCIe state machine that brings a link up and manages its power states.
RAL
Register Abstraction Layer
UVM's model of a design's registers, with frontdoor and backdoor access.
GDSII
Graphic Design System II
The binary stream format for chip layout — the file that goes to the foundry.
ECO
Engineering Change Order
Post-route incremental fixes — metal or full ECO.
MBIST
Memory BIST
Built-in self-test logic that exercises on-chip memories.
PSS
Portable Stimulus Standard
Accellera spec for portable, intent-level test scenarios.
